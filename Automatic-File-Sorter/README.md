# 📁 Automatic File Sorter

An automation script that scans a designated folder and automatically organizes files into specific subfolders (`csv files`, `image files`, `text files`) based on their extensions.

## 🎯 Features
* Automatic folder creation if they don't exist.
* File extension checking (`.csv`, `.png`, `.txt`).
* Automated file movement to destination folders.

## 🛠️ Tech Stack
* Python 3
* Built-in libraries: `os`, `shutil`
